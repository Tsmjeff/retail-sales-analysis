# Retail Sales Performance Analysis

## Project Overview

This project analyzes retail transaction data from 2024–2025 to identify sales trends, customer behaviour, product performance, discount patterns, and payment preferences.

The goal of the analysis is to transform raw sales data into useful business insights that can support better decision-making.

## Business Questions

- Which products generate the highest sales?
- Which products receive the highest discounts?
- Which customer types contribute the most to sales?
- Which payment methods are most frequently used?
- Which payment method is most associated with Excellent transaction ratings?
- What sales trends can be identified across the dataset?

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- Power BI

## Data Cleaning

The dataset required several cleaning steps before analysis, including:

- Removing blank rows
- Handling missing values
- Standardizing inconsistent product categories
- Correcting spelling errors in product names
- Reviewing negative values
- Separating sales transactions from returns and other transaction types
- Creating calculated sales values where required

## Analysis

The cleaned dataset was analyzed using Excel PivotTables and Power BI.

The analysis focused on:

- Product performance
- Sales performance
- Customer behaviour
- Discount patterns
- Payment methods
- Transaction ratings
